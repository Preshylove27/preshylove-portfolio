# Preshy Love Portfolio

A personal developer portfolio website for Preshy Love, built with HTML, CSS, Bootstrap, and JavaScript.

## Features

- Responsive single-page portfolio layout
- Hero section and modern developer branding
- About, skills, featured project, services, future projects, and contact sections
- Bootstrap-based styling and custom polished design
- Smooth scroll navigation and subtle reveal animations

## Run locally

1. Open the project folder in a browser, or serve it locally with a simple static HTTP server.
2. From the project root, run:

```bash
python -m http.server 8000
```

3. Open http://localhost:8000 in your browser.

## Notes

- The contact form is front-end only and does not send emails.
- Placeholder personal details are included where exact information was not provided.
